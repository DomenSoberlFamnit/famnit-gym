# About

A collection of Gymnasium environments used with the Intelligent Systems course at UP FAMNIT.

# Installation

```console
pip install famnit_gym@git+https://github.com/DomenSoberlFamnit/famnit-gym
```

# Environments

| Environment | Type | Documentation |
|-------------|------|---------------|
| Sokoban | Single-agent (Gymnasium) | [docs/sokoban.md](docs/sokoban.md) |
| Mill (Nine men's morris) | Multi-agent (PettingZoo) | [docs/mill.md](docs/mill.md) |
| Astronaut | Single-agent (Gymnasium) | [docs/astronaut.md](docs/astronaut.md) |
